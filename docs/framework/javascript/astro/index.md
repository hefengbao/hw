## 资讯

### Astro 7 重写编译器与 Markdown 流水线

`.astro` 编译器已使用 Rust 重写，Markdown 和 MDX 处理迁移到新的 Rust 流水线，渲染切换到基于队列的引擎，框架现在则基于 [Vite 8](https://vite.dev/blog/announcing-vite8) 及其 Rolldown 打包器运行。

Markdown 现在通过 [Sätteri](https://satteri.bruits.org/) 运行。
