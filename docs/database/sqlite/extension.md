# Extension

## Extension Formats

Depending on the platform, compiled extensions will have different formats:

| Platform | File Extension         |
| -------- | ---------------------- |
| Linux    | `.so`                  |
| Android  | `.so, .aar`            |
| macOS    | `.dylib, .xcframework` |
| iOS      | `.dylib, .xcframework` |
| Windows  | `.dll`                 |
